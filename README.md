# Automação de Tarefas com Python

Este repositório contém um projeto de automação de processos desenvolvido com Python. O objetivo principal foi criar um robô capaz de interagir com o navegador e sistemas web para realizar tarefas repetitivas de forma automatizada.

## 🚀 Funcionalidades
- **Navegação Automatizada:** Interação com o navegador Chrome para acessar sistemas internos.
- **Login:** Automação de preenchimento de formulários de login.
- **Processamento de Dados:** Utilização de bibliotecas para leitura e manipulação de bases de dados (CSV).

## 🛠️ Tecnologias Utilizadas
- **Python**
- **PyAutoGUI:** Para automação de cliques e digitação.
- **Pandas:** Para manipulação de bases de dados.

## 📂 Como utilizar
1. Instale as bibliotecas necessárias: 
   `pip install pyautogui pandas`
2. Execute o arquivo `automatos_tarefas.py`.
